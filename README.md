Game Name: Jungle Journey

Description: Jungle Journey is a fun 2D adventure game set in a deep forest. What starts as a peaceful camping trip with your girlfriend quickly turns into a big mission when your campfire runs out of wood. You walk into the dark forest to pick up logs, but you find a mysterious cave. When you go inside to look around, the entrance falls apart and traps you underground

PROJECT STRUCTURE
-assets (contains all the assets and images)
-music (contains all the music and sound effects)
-scene (contains all the scenes and levels)

This game is based on 3 levels 
* the main scene (level 1) - Lobby
* the forest scene (level 2) - Difficuilty Easy
* the cave scene (level 3) - Difficuilty Medium
* the end scene (last level) - Escape
